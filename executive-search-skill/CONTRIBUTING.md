# Contributing to Executive Search Intelligence Skill

Thank you for your interest in contributing! This skill is open source and we welcome improvements.

## Guidelines

### What We Accept

✅ **Workflow improvements** - Better search strategies, scoring refinements  
✅ **Additional examples** - New fictional search scenarios (must be anonymized)  
✅ **Bug fixes** - Corrections to templates, documentation, instructions  
✅ **Documentation** - Clearer explanations, additional guides  
✅ **Scripts/automation** - Tools that improve the skill functionality  

### What We Don't Accept

❌ **Real client information** - All examples must be fictional  
❌ **Candidate PII** - No real candidate names, emails, phone numbers  
❌ **Proprietary methodologies** - Don't copy from other search firms  

## Privacy & Confidentiality

**Critical:** This skill is used by executive recruiters who handle confidential client relationships.

- All examples MUST use fictional company names
- All candidate names MUST be made up
- No identifying details from real searches
- When in doubt, anonymize more

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/your-improvement`)
3. **Make your changes**
4. **Anonymize any examples** (use fictional names/companies)
5. **Test your changes** (does it work with OpenClaw?)
6. **Submit a pull request**

## Example Contribution: Adding a Search Scenario

If you want to add a new example search:

1. Create a new folder in `examples/` (e.g., `examples/yourcompany-role/`)
2. Use a **fictional company name** (e.g., "TechCorp Fintech")
3. Include:
   - `README.md` with company profile, role requirements, search strategy
   - 3-5 candidate scorecards (fictional names)
   - Availability analysis
   - Methodology notes
4. Mark clearly as **FICTIONAL EXAMPLE** at the top

## Code of Conduct

- Be respectful and professional
- Respect confidentiality requirements
- Provide constructive feedback
- Help maintain the skill's quality and safety
